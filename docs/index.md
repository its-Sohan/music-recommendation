# Music Recommendation Engine

Welcome to the Music Recommendation Engine documentation.

## Overview

A web application that provides music recommendations using:
- **Collaborative Filtering** via ALS
- **Cosine Similarity** via FAISS
- **FastAPI** for the backend
- **React** for the frontend
