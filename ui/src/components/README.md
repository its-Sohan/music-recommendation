# Components

This directory contains React components for the music recommendation UI.

## Components

| Component | Description |
|-----------|-------------|
| `SearchBar` | Song search input with autocomplete |
| `SeedBasket` | Selected seed songs display |
| `ResultsGrid` | Recommendation results display |
| `SongCard` | Individual song card component |
| `LoadingSpinner` | Loading indicator |
| `ErrorMessage` | Error display component |
